# HermesStatus documentation

[中文文档](zh-CN/README.md)

This documentation set describes the code currently maintained on `2.0`. It
does not preserve historical migration plans, release gates, or retired
topologies from earlier iterations of the project.

| Document | Purpose |
| --- | --- |
| [Architecture](ARCHITECTURE.md) | Components, data flow, dashboard scope, and non-goals. |
| [Configuration](CONFIGURATION.md) | Server, Client, Hermes, Lucky, and multi-device configuration. |
| [Deployment](DEPLOYMENT.md) | Local Compose, production deployment, and the SMART device boundary. |
| [Security](SECURITY.md) | Trust boundaries, credentials, and safe exposure rules. |
| [Operations](OPERATIONS.md) | Health checks, stale data, backup, upgrade, and troubleshooting. |
| [Development](DEVELOPMENT.md) | Local validation and pull-request workflow. |

The Chinese documents are translations of this document set. Keep changes to
both languages in the same pull request.
